# Security

Sussi is a front-end design system: CSS, tokens and React components, with no server and no data. Security issues are still possible (for example an XSS through a component that renders HTML).

Please report them privately with GitHub's **Report a vulnerability** (Security tab of the repository), not in a public issue. You will get an answer within a week. Fixes go out as a patch release and are listed in `CHANGELOG.md`.

**Norsk:** Meld sikkerhetsfeil privat via «Report a vulnerability» på GitHub, ikke i en åpen sak.
