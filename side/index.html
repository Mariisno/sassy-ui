Sussi.

This page is also in English.

Et lite, varmt designsystem for rolige hverdagsapper: tokens, CSS og React-komponenter, laget for WCAG 2.2 AA i lys og mørk modus. Laget av Mari Notland (NotlandDesign) og oppkalt etter katten hennes. Norsk som standard, engelsk der du trenger det.

Rask start

Med bare CSS er det én linje i <head>:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/Mariisno/sussi-ui@v0.9.0/styles.css">

Med React (18.3 eller 19) installerer du fra GitHub med npm install github:Mariisno/sussi-ui#v0.9.0, så import 'sussi/styles.css' én gang og komponentene fra 'sussi': import { Button } from 'sussi'. Sett data-theme="light" eller "dark" på <html>.

Hele gjennomgangen: Kom i gang.

Dine egne farger

Én farge inn, et helt tema ut, med kontrasten sjekket i lys og mørk modus:

npx sussi-tema --aksent "#2F6F9F" --navn hav > hav.css

Så data-tema="hav" på <html>. I kode: import { lagTema, tilCss } from 'sussi/tema'. Du kan også overstyre flater, tekst og statusfarger, eller sette skrift, radius, avstand og bevegelse. Går en kombinasjon ikke opp med kontrastreglene, får du en tydelig advarsel i stedet for et tema som ikke holder. Seks ferdige aksenter følger med: mose (moss, standard), leire (clay), fjord, lav (lichen), lyng og oker (ochre). Prøv dem i temabyggeren.

Dette er i esken

  • Tokens i CSS (tokens/) og som JSON i W3C-formatet for designtokens (tokens/sussi.tokens.json, også sussi/tokens.json), for Style Dictionary og designverktøy.
  • Komponenter: knapper, skjemafelt, avkrysningsboks, radioknapp, bryter, nedtrekksliste, faner, dialog og bunnark, meny og popover, verktøytips, toast, framdrift, tom tilstand, listerad, badge, tag, kort, et app-skall med fanelinje eller sidestolpe, ikoner (Lucide) og maskoten Sussi.
  • Fonter: Schibsted Grotesk og DM Mono, hostet selv, ingen Google Fonts.
  • Regler som holder: kontrast for hvert tokenpar i lys, mørk og hver aksent, tastatur og skjermleser, 44 px berøringsmål, prefers-reduced-motion.
