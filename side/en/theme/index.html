Make your own theme

One colour in, a whole theme out. The engine (tokens/tema.js) derives the accent group in OKLCH (a colour space where lightness is an axis of its own, so it can move without the hue shifting) and moves lightness only until every pair holds the requirement Sassy puts on its own accents. What you set yourself never moves. Everything runs here in the browser.

Settings

Start from a preset
Accent colour
a–z, 0–9 and hyphens. Becomes data-tema="…".
Empty: the same colour, moved as little as needed.

Your own surfaces and text (optional)

Empty field: the engine derives the value. A value you set never moves.

Take it with you

Load the CSS after styles.css and set data-tema="name" on <html> beside data-theme. The JSON is DTCG (the W3C format for design tokens, which Style Dictionary and design tools read) with the same paths as sassy.tokens.json.
